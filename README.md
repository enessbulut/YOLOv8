# 🚀 YOLOv8 – Computer Vision Suite

This repository presents a comprehensive set of computer vision projects implemented using **YOLOv8**. It covers the core visual perception tasks: image classification, object detection, object tracking, and image segmentation. Each module focuses on practical deep learning applications with real-world datasets and scenarios.

---

## 📌 Image Classification
In this task, a YOLOv8-based classification model is trained on a medical imaging dataset containing **COVID-19**, **Normal**, and **Viral Pneumonia** chest X-ray images.  
The objective is to accurately classify input images into these categories, demonstrating the use of deep learning for healthcare-oriented image analysis.

**Key highlights:**
- Multi-class image classification  
- Medical dataset (COVID-19 & Pneumonia)  
- End-to-end training and evaluation  

---

## 🧠 Object Detection
For object detection, a YOLOv8 detection model is trained on a **brain tumor dataset**.  
The model learns to localize tumor regions within medical images by drawing bounding boxes around affected areas, highlighting YOLOv8’s detection capabilities in medical imaging.

**Key highlights:**
- Brain tumor detection  
- Bounding box localization  
- Medical image analysis use case  

---

## 🚗 Object Tracking
In the object tracking task, a road traffic video is used as input.  
The system detects and continuously tracks **moving vehicles** across video frames, assigning consistent IDs to each detected car and analyzing their motion over time.

**Key highlights:**
- Video-based object tracking  
- Vehicle detection in traffic scenes  
- Motion-aware tracking  

---

## 🧩 Image Segmentation
The segmentation module focuses on **car part segmentation**.  
Using a YOLOv8 segmentation model, different parts of a vehicle are identified at the pixel level, enabling fine-grained visual understanding beyond bounding boxes.

**Key highlights:**
- Pixel-level segmentation  
- Vehicle part recognition  
- Fine-grained object understanding

## 🎯 Project Goal
The goal of this repository is to demonstrate practical, end-to-end computer vision pipelines using YOLOv8 across multiple tasks and datasets. The project is designed to be reproducible, educational, and suitable for portfolio and academic use.
